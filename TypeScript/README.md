# TypeScript

TypeScript basics: interfaces, readonly and optional properties, index signatures, function interfaces, classes described by interfaces, union types and type predicates, string literal types, ambient declarations (`.d.ts`), namespaces with declaration merging, and nominal typing with brands.

Each `task_N` folder has its own `package.json`, `tsconfig.json` and `webpack.config.js`. Run `npm install` then `npm run build` inside a task folder.
